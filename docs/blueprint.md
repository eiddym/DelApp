# **App Name**: ActaVeraz

## Core Features:

- Guided Workflow: Clear, step-by-step navigation through the voting process: Login, Mesa Confirmation, Photo Capture, Data Entry and Confirmation.
- Vote Data Visualization: Display detailed breakdowns of the recorded votes for each party and category, including any discrepancies that need review.
- AI-Powered Data Extraction: Optical Character Recognition tool for automatically extracting data from the photo of the voting act. Display recognized content, giving the user an option to correct errors before submission
- Session Persistence: The application should temporarily store the collected data, allowing the user to resume their session if interrupted.
- Data Validation and Error Handling: Include error handling for common issues like poor image quality or incorrect data format, guiding the user to resolve the issue effectively.
- Data Anomaly Highlighting: Visually emphasize potential discrepancies or anomalies in entered data to prompt review.

## Style Guidelines:

- Primary color: A moderate blue (#4D80E4) conveys trustworthiness.
- Background color: A very light, desaturated blue (#F2F5FA) creates a calm backdrop.
- Accent color: An analogous blue with higher saturation and lower brightness (#4D6FE4) highlights important elements.
- Headline font: 'Space Grotesk', sans-serif, for headlines and shorter text passages; for longer text, use Inter.
- Body font: 'Inter', sans-serif, is paired with Space Grotesk and used for longer passages of body text.
- Use flat, geometric icons with rounded edges, using the primary blue as the fill color.
- Maintain a clean, grid-based layout with generous white space for readability. Utilize cards and clear section divisions to organize information.
- Incorporate subtle transitions and animations to enhance the user experience, such as sliding panels or fade-in effects when navigating between steps.
